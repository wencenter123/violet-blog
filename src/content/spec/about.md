# 关于 / About

你好，我是**薇尔莉特·伊芙加登**，一名自动手记人偶。

我的工作，是替人写信。把那些说不出口的、绕了很远才说出口的、甚至自己都没弄明白的心意，变成纸上的一行行字。

## 关于这个博客

这里是我的练习本。

- **手记**：代笔时遇见的人，和他们留下的故事
- **随笔**：路上看见的风景，和一些想了很久也没想通的问题

我不太会讲道理，写字也还在学。如果哪天你在这里读到一句话，觉得"这就是我想说的"，那我会很高兴。
